# 决策搭子 · Decision Buddy

一个帮助拿不定主意的人做选择的 AI skill。像有主见的朋友聊天：先问你为什么纠结，再给有理由的建议。

适用于吃什么、周末安排、买东西、项目优先级和工作生活中的选择。小事简短聊，大事认真权衡；你说“直接帮我选”，它就少问一点。默认连着说，少套话，不把每个选择写成分析报告。

## 安装

把这个仓库下载或克隆到本地，将整个 `decision-buddy` 文件夹放到你的技能目录，例如 Codex 的 `~/.codex/skills/decision-buddy`。如果仓库本身已经位于这个目录，无需再复制。

此仓库根目录就是 skill 文件夹，包含 `SKILL.md` 和 `agents/openai.yaml`。不同 AI 工具的技能目录和加载方式可能不同，请按所用工具的要求添加。

## 使用

显式调用示例：

```text
$decision-buddy 我周末想去爬山，又想在家待着，帮我选一下。
```

支持自动发现技能的环境中，也可以直接说“帮我选一下”或“我拿不定主意”。

## 对话示例

**你：** 周末去爬山还是在家待着？

**搭子：** 你是想出去透口气，但又觉得累，还是还有别的顾虑？

**你：** 这周太累了，但在家待着又觉得浪费周末。

**搭子：** 那就在家休息吧，这周已经够累了。要是待到下午想出门，再去附近走走，不用安排一整天爬山。

## 设计原则

- 先理解纠结的原因，不根据题目大小机械拍板。
- 按你的目标和底线推荐，不替你设定价值观。
- 给明确建议，承认代价和不确定性。
- 默认短段落，一次问一个关键问题。
- 不编造事实；建议购买或预订不等于自动执行。

涉及健康、法律或财务的决定时，区分个人偏好和需要核实的专业事实。
